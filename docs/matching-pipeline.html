QRious 최종 매칭 산출

사전 접수 마감 후 한 번 도는 배치. 남·여 전 쌍에 세 점수를 매기고, 그리디로 겹치지 않는 1:1 짝을 고른다.

최종 식 (기본 가중치 1 : 6 : 3) EX가 있으면 final = 0.10·MBTI + 0.60·TAG + 0.30·EX. 세 항 모두 0~1. EX가 완전 결측이면 그 항을 빼고 0.10/0.70 · MBTI + 0.60/0.70 · TAG.

전체 흐름

1. 입력과 쌍 생성

성별로 두 그룹을 나눈 뒤 가능한 모든 (남, 여) 쌍을 만든다. 기준 그룹은 두지 않는다. 남 50 · 여 40이면 쌍은 항상 2,000개다.

have / want필수 키워드 집합
MBTI 4글자E/I · N/S · T/F · J/P
ex_have / ex_want선택 자유 텍스트

2. 쌍마다 세 점수

각 점수는 0~1로 맞춘 뒤 가중 합한다. 방향이 두 개인 점수는 조화평균으로 합친다. 한쪽만 높으면 전체가 내려간다.

기본 가중치 1 : 6 : 3  ·  MBTI 10% · TAG 60% · EX 30%  ·  대안은 2:5:3

TAG 60%

키워드 포함계수. 상대의 여분 매력은 분모에 넣지 않는다.

a = |A.want ∩ B.have| / |A.want|

b = |B.want ∩ A.have| / |B.want|

TAG = 2ab / (a + b)

a = b = 0 이면 0. 범위 0~1, 정규화 없음.

MBTI 10%

축마다 0 또는 1. 합을 4로 나눈다.

E/I  다르면 1

N/S  같으면 1

T/F  같으면 1

J/P  다르면 1

MBTI = (0~4) / 4

EX 30%

이상형 문장과 매력 문장만 비교한다. 자기소개끼리 비교하지 않는다.

a = cos(A.ex_want, B.ex_have)

b = cos(B.ex_want, A.ex_have)

둘 다 있으면 EX = 2ab / (a + b)

코사인은 0 미만을 0으로 자른 뒤 조화평균에 넣는다.

3. EX 빈칸

선택 필드이므로 빈칸은 0점이 아니다. 한 방향을 쓰려면 그 방향의 두 칸이 모두 있어야 한다. 빈 문자열은 임베딩하지 않는다.

가용 방향EX 점수최종 합산
A→B, B→A 둘 다H = 2ab / (a + b)0.10 M + 0.60 T + 0.30 EX
한 방향만그 코사인 ÷ 20.10 M + 0.60 T + 0.30 EX
둘 다 결측EX 항 삭제0.143 M + 0.857 T

한 방향만 있을 때 ÷2 하면, 가중치 0.30을 유지해도 기여 상한은 0.15로 줄어 양방향 조화평균과 균형이 맞는다. 둘 다 없으면 0을 넣지 않고 가중치를 다시 나눈다.

4. 1:1 배정

전 쌍을 한 테이블에 모아 순위만 매기면 같은 사람이 여러 번 뽑힌다. 점수로 정렬한 뒤, 뽑힌 두 사람을 포함하는 나머지 쌍을 지운다.

순서동작
1모든 쌍을 final 내림차순으로 정렬한다.
2가장 높은 쌍 (A, B)를 확정 짝으로 넣는다.
3A 또는 B가 들어 있는 나머지 쌍을 목록에서 지운다.
4목록이 빌 때까지 2~3을 반복한다.
5짝이 없는 사람(인원 불균형)은 미매칭으로 남긴다.

총학에 넘기는 산출물은 전체 1~N위가 아니라 확정 짝, 각 짝의 점수와 이유, 미매칭 명단이다. 이유는 TAG 교집합 키워드를 그대로 적으면 된다.
